## 一、题目要求

给定一个整数数组 `nums`，找出所有满足：

```text
nums[i] + nums[j] + nums[k] = 0
```

的三元组。

要求：

1. 三个下标不能相同。
2. 返回的是数字组合。
3. 答案中不能出现重复三元组。

示例：

```python
nums = [-1, 0, 1, 2, -1, -4]
```

排序后：

```python
[-4, -1, -1, 0, 1, 2]
```

正确结果：

```python
[
    [-1, -1, 2],
    [-1, 0, 1]
]
```

---

## 二、核心思路

三数之和可以理解为：

```text
固定第一个数字 a
然后寻找两个数字 b、c
使得：

a + b + c = 0
```

固定 `a` 后，就变成：

```text
b + c = -a
```

因此使用：

```text
排序 + 固定一个数 + 左右双指针
```

整体步骤：

```text
1. 先排序
2. 枚举第一个数字 nums[i]
3. left = i + 1
4. right = n - 1
5. 计算三个数字之和 total
6. total < 0：left 右移
7. total > 0：right 左移
8. total == 0：记录答案
9. 对 i、left、right 去重
```

## 三、标准代码

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()                                      # 先排序
        res = []                                         # 保存最终答案
        n = len(nums)                                    # 数组长度

        for i in range(n - 2):                           # 固定第一个数字

            if nums[i] > 0:                              # 第一个数已经大于 0
                break                                    # 后面更大，不可能和为 0

            if i > 0 and nums[i] == nums[i - 1]:         # 固定数字重复
                continue                                 # 跳过，避免重复答案

            left = i + 1                                 # 左指针
            right = n - 1                                # 右指针

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total < 0:                            # 和太小
                    left += 1                            # 左指针右移，使和变大

                elif total > 0:                          # 和太大
                    right -= 1                           # 右指针左移，使和变小

                else:
                    res.append(
                        [nums[i], nums[left], nums[right]]
                    )

                    while left < right and nums[left] == nums[left + 1]:
                        left += 1                        # 左侧去重

                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1                       # 右侧去重

                    left += 1                            # 继续寻找下一组答案
                    right -= 1

        return res
```

## 四、为什么要先排序

排序以后：

```text
左边数字较小
右边数字较大
```

因此可以根据当前三数之和决定双指针移动方向。

如果：

```python
total < 0
```

说明当前三数之和太小，需要换一个更大的数字：

```python
left += 1
```

如果：

```python
total > 0
```

说明当前三数之和太大，需要换一个更小的数字：

```python
right -= 1
```

因此可以记：

```text
和小：左指针右移
和大：右指针左移
和为 0：记录答案
```

排序还有一个重要作用：让重复数字相邻，方便后续去重。

## 五、为什么需要去重

题目要求的是：

```text
不能出现重复的三元组
```

例如：

```python
nums = [-1, -1, 0, 1, 1]
```

虽然可以由不同下标组成多个：

```python
[-1, 0, 1]
```

但答案中只能出现一次：

```python
[[-1, 0, 1]]
```

三数之和需要处理三处去重。

### 1. 固定数字 `i` 去重

```python
if i > 0 and nums[i] == nums[i - 1]:
    continue
```

含义：

> 当前固定数字与上一轮相同，上一轮已经搜索过以这个数字开头的所有组合，因此这一轮直接跳过。

### 2. `left` 去重

找到一个答案以后：

```python
while left < right and nums[left] == nums[left + 1]:
    left += 1
```

跳过左侧连续重复数字。

### 3. `right` 去重

```python
while left < right and nums[right] == nums[right - 1]:
    right -= 1
```

跳过右侧连续重复数字。

注意：

```text
去重并不是说数字不能重复。
```

例如：

```python
[-1, -1, 2]
```

是合法答案。

真正不能重复的是：

```python
[
    [-1, -1, 2],
    [-1, -1, 2]
]
```

---

## 六、为什么有 `nums[i] > 0` 就可以结束

代码：

```python
if nums[i] > 0:
    break
```

数组已经排序。

如果当前固定的第一个数字都已经大于 `0`，那么后面的数字只会更大，因此：

```text
正数 + 正数 + 正数 > 0
```

不可能再得到 `0`。

所以可以直接结束整个循环。

这里必须写：

```python
nums[i] > 0
```

不能写：

```python
nums[i] >= 0
```

因为：

```python
[0, 0, 0]
```

是合法答案。

---

## 七、`total` 为什么不用提前初始化

代码：

```python
while left < right:
    total = nums[i] + nums[left] + nums[right]
```

`total` 是每一轮 `while` 中根据当前三个位置临时计算出来的值。

执行顺序：

```text
进入 while
→ 计算 total
→ 判断 total
→ 移动指针
→ 下一轮重新计算 total
```

因此不需要提前写：

```python
total = 0
```

因为进入循环以后马上就会重新赋值。

可以记：

> 变量如果在第一次使用之前一定会被赋值，就不需要提前初始化。

## 八、完整执行过程

输入：

```python
nums = [-1, 0, 1, 2, -1, -4]
```

排序：

```python
[-4, -1, -1, 0, 1, 2]
```

### 第一轮：固定 `-4`

```text
i = 0
nums[i] = -4
left = 1
right = 5
```

当前：

```text
-4 + (-1) + 2 = -3
```

小于 `0`：

```python
left += 1
```

继续寻找，但最终这一轮没有答案。

### 第二轮：固定 `-1`

```text
i = 1
nums[i] = -1
left = 2
right = 5
```

计算：

```text
-1 + (-1) + 2 = 0
```

找到：

```python
[-1, -1, 2]
```

继续移动指针。

下一组：

```text
-1 + 0 + 1 = 0
```

找到：

```python
[-1, 0, 1]
```

最终：

```python
[
    [-1, -1, 2],
    [-1, 0, 1]
]
```

## 九、今天遇到的代码问题

### 1. Python 缩进层级

正确层级：

```python
class Solution:
    def threeSum(...):

        for i in ...:

            if ...:
                ...

            if ...:
                ...

            left = ...
            right = ...

            while left < right:
                ...

        return res
```

重点：

```text
left = i + 1
right = n - 1
while left < right
```

它们都属于 `for` 循环内部，并且和两个 `if` 同级。

`return res`：

```text
和 for 同级
```

因此：

```text
在 for 外
但仍然在 threeSum 函数内
```

### 2. `continue` 后不能放本轮还需要执行的代码

错误：

```python
if i > 0 and nums[i] == nums[i - 1]:
    continue

    left = i + 1
```

一旦执行 `continue`，当前这一轮循环会立即结束，后面的代码不会执行。

正确：

```python
if i > 0 and nums[i] == nums[i - 1]:
    continue

left = i + 1
right = n - 1
```

### 3. Python 缩进统一使用 4 个空格

避免 Tab 与空格混用。

## 十、时间复杂度

排序：

```text
O(n log n)
```

固定一个数字：

```text
O(n)
```

每次固定后，双指针最多扫描一遍：

```text
O(n)
```

因此主体复杂度：

```text
O(n × n) = O(n²)
```

最终：

```text
时间复杂度：O(n²)
```

## 十二、最小背诵版本

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()
        res = []
        n = len(nums)

        for i in range(n - 2):
            if nums[i] > 0:
                break

            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left = i + 1
            right = n - 1

            while left < right:
                total = nums[i] + nums[left] + nums[right]

                if total < 0:
                    left += 1

                elif total > 0:
                    right -= 1

                else:
                    res.append([nums[i], nums[left], nums[right]])

                    while left < right and nums[left] == nums[left + 1]:
                        left += 1

                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1

                    left += 1
                    right -= 1

        return res
```

## 十四、面试口述

> 我先对数组进行排序，然后枚举三元组中的第一个数字。对于每个固定的 `nums[i]`，使用左右双指针寻找另外两个数字。如果三数之和小于 0，就右移左指针使结果增大；如果大于 0，就左移右指针使结果减小；如果等于 0，就记录当前三元组。为了避免重复答案，需要分别对固定数字、左指针和右指针进行去重。整体时间复杂度是 O(n²)。
