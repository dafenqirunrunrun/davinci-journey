Agent记忆系统：

起因：大模型时无状态的

持续对话能力，个性化能力，任务连续性，减少context pressure

短期记忆和长期记忆

短期记忆（conversation history）：当前任务和当前会话产生的信息

长期记忆（memory storage+memory retrieval）：具有长期价值的信息

用户信息+任务经验+重要事实（业务系统中的配置参数）+知识补充
